# FreqaiTrend — 趋势策略+FreqAI 实验归档

> 新策略线（2026-09-16）：4h趋势策略 + FreqAI。与VolatilityGrid（网格/均值回归）互补的方向性探索。
> 环境：70测试服；FreqAI walk-forward；LightGBM；特征/标签见下。

## 背景与研究前置
- 30m方向不可预测（IC≈0/AUC0.506，见FreqAI_MLpilot_结果.md）
- **4h尺度方向预测力pilot（新）**：5币4h，特征池15维，训练2024-02→2026-04/测试2026-05→09

| 目标 | IC | AUC | 判读 |
|---|---|---|---|
| 未来12h | -0.000 | 0.484 | 无 |
| 未来24h | +0.019 | 0.502 | 无 |
| 未来48h | +0.034 | 0.505 | 弱 |
| **未来4天** | **+0.176** | **0.564** | **有真实预测力** |

结论：4h方向预测的合理horizon=4天 → 策略标签定为 `&-s_close = close.shift(-24)/close - 1`。

## 策略设计（v1/v2）
- 周期4h，can_short，3x，每笔风险1%（按2×ATR止损反推），max_open_trades=3
- FreqAI特征：RSI/ATR/SMA-EMA距离/收益率（周期6,12,24扩展）+量比+时段；标签=未来4天收益
- 风控：2×ATR硬止损 + 2×ATR触发/3×ATR吊灯 + 30根时间止损 + ema50反向regime退出
- **对照组**：`use_ml=False` → 纯机械（同结构，仅用动量过滤）

**v1**（入场=close vs ema50 + ML预测>±1.5%）→ ema50两侧churn严重

**v2**（入场=30根突破 + ema200 regime + ML预测>±1.5%）→ 交易量正常化

## 阶段性结论
1. **FreqAI增量价值稳定存在**：两个版本中ML版均优于同口径机械版（v1: +23pp；v2: +5.6pp且DD减半）——4h方向预测力（IC 0.18@4天）是真实的
2. **结构改进有效**：突破版远好于churn版（653→77笔、-26%→-9.6%、DD 40.5%→13.6%）
3. **但样本期趋势策略逆风**：2026年样本以震荡为主，纯趋势（无论ML与否）仍为小亏——趋势线的定位是"与网格互补的多策略组合"，其价值需在趋势regime中体现（样本内未出现）
4. 样本量小（v2仅77笔），结论稳健性有限

## 八、Renko砖块图入场（用户提案，2026-09-16）

**用户描述**：价格100→101画一个方框、102/103各一个；回到102不画；跌破102到101画反向砖——即**Renko图**（固定幅度才出新砖、反向跨越2格才翻向），用来过滤K线噪音、让趋势更明显。

**实现（FreqaiRenko）**：砖块=0.5×ATR14（自适应）；close序列驱动，顺序计算 rk_dir（当前砖向）/rk_run（连砖数）/rk_flip（翻砖事件）；入场两种模式：`flip`（翻砖即入）/`run`（连砖≥3入）；EMA200 regime过滤；出场=反向翻砖/30根时间/A TR吊灯+2×ATR硬止损；ML门槛与机械对照同前。

**结果（2026-01→09，5币）**：

| 变体 | 交易数 | 收益 | PF | DD |
|---|---|---|---|---|
| **flip-mech（翻砖+机械）** | 340 | **+1.82%** | **1.02** | 18.37% |
| flip-ML（翻砖+ML） | 170 | -0.73% | 0.98 | 11.23% |
| run-ML（连砖≥3+ML） | 265 | -8.66% | 0.85 | 19.36% |
| run-mech（连砖+机械） | 552 | -20.49% | 0.84 | 45.10% |

**全期（2025-01→2026-09）**：flip-ML 356笔/-3.76%/PF0.96/DD13.50%；**flip-mech 730笔/+19.50%/PF1.09/DD19.11%**（注：XRP/SOL/BNB的4h数据自2025-01起，前几个训练窗口数据不足被FreqAI跳过；两版本同受影响）。

**结论**：
1. **翻砖(flip)远优于连砖(run)**（差10~20pp）——"买趋势转折的第一块反向砖"有效，"追已确立的趋势"是本市场毒药（与全部历史实验一致）
2. **Renko翻砖显著优于同框架的Donchian突破**（8.5月窗口：-0.7~+1.8% vs -9.6~-15.2%）→ **用户的噪音过滤直觉得到验证**
3. **全期：机械版为正（+19.5%/PF1.09/DD19.1%，20.5个月）**，ML版微亏（-3.76%）——**ML增量在该变体上为负**（与此前Donchian变体ML占优相反）：Renko翻砖本身即alpha来源，ML的4日预测门槛滤掉了部分有效翻砖（机械的ret6动量确认更适配该入场）
4. 无论如何，该策略强度远逊于生产网格V4（同区间+1738%）：定位是"趋势regime互补腿"，需在组合层面体现价值（趋势段独立收益、与网格低相关）
5. 注意：Renko与"raw反转入场"（如无砖块的均线反转）的严格对照未做；"翻转入场 vs 突破入场"是本次结果的主导变量

## 九、Renko参数修正：标准2格翻转 vs 1格敏感版（用户核对实现细节，2026-09-16）

**背景**：用户核对Renko记录方式——标准Renko反向需跨2格才翻向（103→102不画、→101才画）；此前实现为1格翻转（更敏感，跌到102即翻）。修正`reversal_bricks=2`为标准版重测。

| 版本 | 8.5个月窗口(2026-01→09) | 全期20.5个月(2025-01→) |
|---|---|---|
| flip-mech **1格敏感版** | +1.82% / PF1.02 / DD18.4% | **+19.50% / PF1.09 / DD19.1%** |
| flip-mech **标准2格版** | +0.80% / PF1.01 / DD20.1% | **+3.28% / PF1.02 / DD15.3%** |
| flip-ML 1格敏感版 | -0.73% / PF0.98 / DD11.2% | -3.76% / PF0.96 / DD13.5% |
| flip-ML 标准2格版 | -0.06% / PF1.00 / DD7.1% | -5.20% / PF0.90 / DD10.1% |

**结论**：**更严格的2格翻转反而更差**（全期机械版 +19.5%→+3.3%）——多过滤的一格延迟入场、错过趋势启动段；再次验证本市场规律"过滤越多≠越好，奖励更早响应"。1格敏感版（意外地）为更优参数，档案以此为准。砖块尺寸（当前0.5×ATR自适应）仍为未扫描的旋钮。**另：无固定盈利目标**——出场为反向翻砖/30根时间/ATR吊灯，测试中不存在"+X%止盈"。

## 十、Renko砖块尺寸扫描（2026-09-16）

**设置**：机械版（use_ml=False）、1格翻转、全期2025-01→2026-09、5币。

| 砖块 | 交易 | 收益 | PF | DD | 收益/DD |
|---|---|---|---|---|---|
| ATR×0.15 | 1391 | +23.54% | 1.07 | 33.2% | 0.71 |
| ATR×0.2 | 1219 | +22.99% | 1.08 | 31.2% | 0.74 |
| **ATR×0.3** | 1017 | **+40.00%** | **1.15** | 25.2% | **1.59** ★ |
| ATR×0.5 | 730 | +19.50% | 1.09 | 19.1% | 1.02 |
| 固定0.75% | 779 | +15.10% | 1.07 | 20.9% | 0.72 |
| 固定1.5% | 486 | +0.17% | 1.00 | 15.1% | 0.01 |
| ATR×1.0 | 453 | -17.32% | 0.85 | 21.1% | — |

**结论**：①**倒U型，最优点≈0.3×ATR**（+40.0%/PF1.15/DD25.2%；收益/DD=1.59 仍为全组最优）；②过细（0.15/0.2）→换手与DD暴涨（1391笔/DD33%）、收益反降；过粗（≥0.5）→错过趋势启动段；③**固定百分比砖块整体劣于自适应ATR砖块**（0.75%固定+15.1% vs 0.3ATR +40%）；④该线当前最优参数组合=**翻砖入场+机械动量确认+砖块0.3×ATR+1格翻转+EMA200 regime**（全期+40%，年化~23%，与网格V4低相关的互补腿）；⑤ML增量在这条线上持续为负，未在0.3档重测（预期同向）。
