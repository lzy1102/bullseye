# 趋势判断方法对比实验记录

日期：2026-10-10
数据：25 只 A 股日线（银行 7 + 龙头 18），2023-01 ~ 2026-09，qfq 复权。
口径：状态判定后 20 日前瞻收益（不含未来函数，状态只用当日及以前数据）。
样本注意：25 只均为事后幸存票 + 样本期偏多，判空栏的绝对值不可直接采信，方法间相对排序有效。

## 结果（按 判多后20日平均收益 - 判空后20日平均收益 排序，越靠前越好）

|---|---|---|---|---|---|
| MACD(12,26,9) 信号线 | **+1.21%** | **52.9%** | +1.17% | 19.2 | 100% |

## 结论

1. **MACD 双第一（准确 + 灵敏）**：判多后 +1.21%、唯一胜率 >52%；年翻转 ~19 次（约三周一翻）。
   换手高，但 1.21% 单次期望 >> 0.1% 双边成本。
2. **MA20/60 最钝**（4.6 翻/年）：准确性中等，赢在拿得住、省成本。慢票（银行）适配；快票（中芯）踏空 + 
   回撤深（BaseSpot 中芯回撤 96% 的根因）。
3. **粘连 gap 双输**：收益降（0.83%→0.77%）、翻转翻倍（4.6→9.2）。TrendGrid 的 min_gap_ratio 建议移除。
4. **ADX 方向反指**：判空后 +2.53%（全场最差）。ADX 只配做强度/加仓开关，不做方向状态。
5. **R² 同理**：过滤/仓位用途可以，主状态覆盖率仅 60%。

## 落地建议

- 门禁升级：**双确认** = MACD 翻身（快） + MA20/60（慢）同多才做多；灵敏与稳定各取一半。
- 快票（高振幅）配 MACD 主导，慢票（低振幅银行）维持 MA20/60 即可。
- 复现脚本：`/opt/trendcmp.py`（192.168.3.70，Docker 直跑）。
