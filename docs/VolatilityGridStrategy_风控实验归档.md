# VolatilityGridStrategy 风控实验归档

> 日期：2026-09-04 ｜ 环境：186.241.106.174（Docker freqtrade:stable，OKX 合约数据）
> 结论先行：第一轮（止损/刹车/递减）全败；第二轮**长空窗首单降仓 48h×0.4** 有效（V2）；第四轮**trailing 0.01→0.004** 有效（V3 现 1577%/9.80% vs 原 983%/10.70%）；其余（ma_dive/周线/4h累积/实时/多周期）均失败。

## 基线

- 策略：`VolatilityGridStrategy` + `VolatilityGridStrategy_aggressive_v3.json`

- 结果：**+844.63%**（1000 → 9446 USDT），496 笔，胜率 95.6%，DD 22.65%，PF 2.26，Sharpe(日) 3.92

## 大亏单特征（9 笔 >-100U，占全部亏损 95%）

1. **开仓即开在极端点**：SOL 空 2026-08-19 开在波段最低点 80.84（期间最低 80.63）；ETH 多 2026-01-29 开在距顶 0.9% 处。波动率突破入场天然容易买山顶/空谷底。
2. **等额 DCA 逆势加满**：每笔加仓 ≈ 首仓金额（钱包/7），价格逆行过程中一路加到 6~7 次，名义仓位滚到账户的 3 倍杠杆上限（例：SOL 单最终 36K 名义 / 11K 账户）。5/9 笔大亏是 DCA 加满的单。
3. **钝刀割肉 2~4 天后被日线"斩首"**：全部 20 次 `trend_reversed` 强平都发生在 UTC 00:00 —— 1d 趋势每天只更新一次，盘中反转最晚要等 24h 才确认。
4. **常砍在反弹上**：ETH 2/1 那笔，价格已从 2237 反弹到 2450（+9.5%）仍被强平。
5. **空头亏 3 倍于多头**（-4716U vs -1625U）；SOL 一币贡献 4 笔大亏（-4062U）。

## 为什么每个方案都失败（机制）

- **静态止损**：策略盈利结构 = "无止损扛过深蹲 + DCA 摊平 + 反弹 trailing 止盈"。砍腿把暂时深潜的单变成实亏，还触发重新进场再付手续费（交易数 496→1009）。宽止损反而更差（-25% 比 -12% 更惨），因为锁定的是最深处的单。
- **距离刹车**：5×ATR（≈5%）以内的大量正常补仓被误杀，救援机制瘫痪（触发 9824 次刹车）。
- **趋势刹车**：DCA 的前置条件就是"从极值反弹才补"，补仓那一刻盘面趋势往往刚回暖 → 刹车永远逮不住真正的灾难，却误伤 79pp 利润。
- **递减补仓**：压住了雪球（DD↓）但同步削弱复利投放力度，利润掉得比风险快。
- **移除 SOL**：`max_open_trades=1` 下资金按交易序列复利滚动，去掉一个高信号密度币对会重排整条资金曲线（不是简单减去该币盈亏）。
- **时限出场**：赢家与输家在开仓后前 72h 内的逆行分布几乎重叠（24h 中位 0.84% vs 2.41%，赢家 P99=6.57%）——"急速反向不回头"只在事后可辨，任何阈值都是错杀 2~3U 盈利换 1U 避损。

## 第二轮实验（V2 副本）—— 找到有效改进

### ✅ 有效：长空窗首单降仓（gap guard，已实装 V2）

**数据发现**：大亏单开仓前的空窗期远长于赢家（均值 63h vs 5.8h，赢家中位仅 2h）。"空窗≥24h 首单"是全部分析中唯一整组为负的信号（24 笔合计 -1194U）；最惨的 SOL -2390U 正是静默 500h（20.8 天）后的首单。机制：空窗 = 波动率过滤在挡行情（死水期），死水后第一波常是暴力突破，网格恰好开在突破极端点。

**规则**：距上一笔平仓超过 `gap_threshold_h` 小时 → 本笔首单仓位 × `gap_stake_factor`。实装于 `VolatilityGridStrategyV2.custom_stake_amount`。

|---|---|---|---|
| 基线 | +844.63% | 22.65% | 2.26 |
| 24h / ×0.5 | +866.05% | 13.22% | 2.71 |
| 48h / ×0.5 | +889.73% | 12.68% | 2.71 |
| 72h / ×0.5 | +942.58% | 12.45% | 2.75 |

| 72h / ×0.3 | +979.99% | 17.66% | 3.00 |

**样本外分段验证（规则只在 2026 年真正触发）**：
- 2025 年（平静期）：基线 +511.92%/DD 26.00% vs V2 +508.65%/26.00% → 几乎不触发，代价 -3pp
- 2026 年（含灾难）：基线 +54.05%/DD 22.64% vs V2 **+73.93%/17.65%** → 多赚 20pp 且回撤下降

行为呈理想"保险"形态：平时免费，出事救命。参数在 24~72h、×0.4~0.5 区间均双改善，不依赖单一取值。

### ✅ 有效：亏损周期调仓（已实装 V3 并部署李志勇，2026-09-11）

**数据发现（527 笔/591 天）**：亏损频率统计——每月约 1.2 次亏损、每 23 笔一次亏损（间隔中位 22 笔）、每 28 笔一次满仓深补。漂移率分析（P(亏损|距上次亏损k笔)）显示**亏损非随机**：刚亏完窗口风险≈0%，从第 18 笔起抬升（7-9%），≥27 笔达 10-22%（基准 4.4%）——亏损呈"定期到访"。

**规则**：每次开仓前查已平仓交易序列，连续盈利笔数 (`since_loss`) ≥ `loss_throttle_start(18)` → 首仓 × `throttle_factor(0.5)`；一旦亏损平仓计数归零、恢复满仓。实装于 `VolatilityGridStrategyV3.custom_stake_amount`（`get_trades_proxy` 读交易库，无状态现算）。

|---|---|---|---|
| V3 前版 | 1482.53% | 3.74 | 7.57% |

**三重验证**：
- 分季度：25Q2 双赢（+17pp、DD 26%→12.9%）、25Q4 DD 腰斩，其余持平不恶化
- 平台：15-19 全在 DD 4.52% 平台（非刀锋），阈值约 0.8×中位间隔
- 样本外（6 个未参与发现币对）：旧 +186.16%/PF1.08/DD87.4% → 新 **+570.18%/PF1.55/DD45.3%**，三项全改善
