# ETF 轮动实验归档（2026-10-29）

> 动机：单票日线技术策略在留出股票池上全部失效（见
> `docs/龙头结构区域_实验归档.md` 第十节）。ETF 轮动是成本最低、容量最大、
> 逻辑最透明的另一条路，先验证它。
> 脚本：`scripts/research/fetch_etf_data.py`（数据）、`etf_rotation.py`（回测）。
> 口径：baostock 前复权日线 2013-2026，月频调仓，费 0.05%/边（另做 0.1%/0.2% 敏感性）。

---

## 一、标的与规则

| 类别 | 标的 |
|---|---|
| 风险资产 | 510300 沪深300、510500 中证500、512100 中证1000、159915 创业板、510880 红利、512880 证券、518880 黄金 |
| 避险 | 511010 国债（511880 货币备用） |

轮动规则：
1. 动量分 = 收盘 / `lookback` 日前收盘 − 1
2. 风控：只保留收盘站上自身 MA200 的标的（月度检查 + 可选每日检查）
3. 取分数最高的 N 个等权持有，下月首个交易日调仓
4. 全部不满足 → 全部换成国债 ETF
5. 费用：换手按 0.05%/边

## 二、先踩了一个未来函数（必须记录）

第一版回测得到 `mom20 top1 + guard + abs` 全窗口 **CAGR 19.98%、DD −34%、Sharpe 0.98**，
"等权 + 300 指数 MA200 过滤"更是 CAGR 19.65%、Sharpe 1.38。

**但那是同日信号**：用当天收盘算出的权重，套用到当天（含）的收益上。
修正为 `权重.shift(1)`（收盘决策，从下一根开始计收益）后：

| 方案 | 修正前 CAGR / Sharpe | **修正后 CAGR / Sharpe** |
|---|---|---|
| 轮动 mom20 top1 g+a | 19.98% / 0.98 | **8.45% / 0.50** |
| 等权 + 300 MA200 | 19.65% / 1.38 | **7.79% / 0.62** |

差异巨大。A 股日频回测里，"同日收盘信号 + 同日收益"是最常见的未来函数，
本次在 ETF 上又复现了一次。

## 三、修正后的结果

| 窗口 | 轮动 mom20 top1（CAGR/DD/Sharpe） | 等权持有 7 只 | 等权 + MA200 切国债 | 300 买入持有 |
|---|---|---|---|---|
| 2014-2019 | 9.74% / −52.1% / 0.51 | 6.72% / −41.2% / 0.46 | **8.95% / −27.0% / 0.72** | 11.60% / −45.5% / 0.57 |
| 2020-2022 | 1.45% / −20.3% / 0.17 | 4.00% / −23.9% / 0.29 | **5.74% / −12.7% / 0.46** | −0.79% / −37.7% / 0.06 |
| 2023-2026 | **23.36% / −27.6% / 1.06** | 9.77% / −19.9% / 0.62 | 7.65% / −15.8% / 0.57 | 5.16% / −22.6% / 0.39 |
| 全窗口 | 9.86% / −55.5% / 0.53 | 6.95% / −41.2% / 0.47 | **7.79% / −27.0% / 0.62** | 6.79% / −45.5% / 0.42 |

参数网格（lookback 10/20/40/60/120 × top1/2/3 × 是否每日风控）全部落在
CAGR 5~10%、DD −42~−65%、Sharpe 0.35~0.53 区间，没有稳定优于基准的格点。

## 四、判决

1. **动量轮动不成立**：全窗口 CAGR 9.86% 只比 300 的 6.79% 高一点，但
   最大回撤 −55.5% 比买入持有还大，Sharpe 0.53 也只是略好；2020-2022 只有 1.45%。
   它的高收益完全集中在 2023-2026 一段（+23.4%），是单一行情，不是稳定 edge。
2. **"等权持有 + 300 指数 MA200 切国债"是唯一站得住的**：
   全窗口 Sharpe 0.62（基准 0.42）、回撤 −27%（基准 −45%），每个窗口 Sharpe 都优于 300。
   但 CAGR 7.79% ≈ 基准 6.79%，**是降波动，不是提收益**。
3. **越简单的规则越稳**：叠加每日风控、绝对动量过滤、多档参数，反而都在
   削收益（whipsaw）。这和前面股票策略的结论一致。
4. **收益天花板是真实的**：把未来函数修掉之后，这批公开的、免费的、只用价量的
   规则能给到的最好结果，就是"年化 8%、回撤 −27%、Sharpe 0.6"。
   超过这个量级的回测，先怀疑未来函数或幸存者偏差。

## 五、可以真正落地的版本（弱但干净）

```
标的：510300 / 510500 / 512100 / 159915 / 510880 / 512880 / 518880 + 511010
规则：等权持有 7 只风险 ETF；
      510300 收盘 < 其 MA200 时，全部换成 511010；
      用前一日收盘判断（shift 1），每月复核一次即可（日频检查只会增加换手）；
预期：年化 6~9%，最大回撤 −25~−30%，Sharpe 0.6 左右
```

如果想再稳一点：风险 ETF 70% + 国债 30% 常配，全窗口 CAGR 6.66%、DD −19.4%、Sharpe 0.72。
