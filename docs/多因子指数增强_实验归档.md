# HS300 多因子实验归档（2026-10-29）

> 动机：单票技术策略在留出池全灭、ETF 轮动扣掉未来函数后只剩"分散+趋势过滤"。
> 多因子是业界主流路线，先做一次最小可用验证。
> 数据：baostock 日线（peTTM/pbMRQ/turn）+ sina 财务指标（2014 起）+ 证监会行业。
> 口径：HS300 当前成分 300 只，月频调仓，费 0.1%/边，权重 shift(1)（收盘决策、下一根计收益）。

---

## 一、因子与构造

| 因子 | 定义 | 方向 |
|---|---|---|
| value | 1 / pbMRQ | 高 |
| quality | 净资产收益率 ROE（最新已披露） | 高 |
| growth | 净利润同比增长 | 高 |
| mom | `close[t-21] / close[t-252] - 1`（12-1 动量） | 高 |
| lowvol | 60 日收益标准差 | 低 |

- 财务数据**滞后期固定 90 天**（数据源无公告日，宁保守）
- 每月末横截面 winsorize(1%/99%) + z-score，等权合成
- 取分数前 N 等权持有，下月首个交易日调仓
- 可选行业上限（证监会一级行业，每行业 ≤6 只）

---

## 二、过程中修掉的两个 bug（都改变了结论）

1. **权重矩阵初始化为 0.0**：`ffill` 只能填 NaN，填不了 0，导致 95% 的时间空仓，
   组合收益 -6% 而基准 +218%。改为初始化为 NaN。
2. **分段回测没有截断收益**：`ret` 用全样本，权重只覆盖窗口，
   导致 2016-2020 段出现 NaN/错乱。改为 `ret = ret.loc[dates]`。

修正后才得到下面的结果。这两类错误（同 bar 收益、窗口未截断）在自研回测里极常见。

## 四、结论

1. **唯一在两个分段都跑赢等权基准的是 `动量 + 低波`（top50）**：
   Sharpe 1.30 vs 0.98（2016-20）、0.89 vs 0.73（2021-26），全窗口 1.07 vs 0.86，
   收益 17.75% vs 15.60%，回撤基本持平。换手约 6.7 次/年，成本可控。
2. **价值/质量在 A 股这十年是拖累**：value=1/PB 会自动重仓银行地产，
   top50 value+quality 只有 10.6% CAGR，Sharpe 0.71，低于等权。
   五因子等权（13.3%）被它拉低，不如只用动量+低波。
3. **topN 越小收益越高、回撤越大**：top20 CAGR 20.6% 但回撤 −37%；
   top50 是风险收益比最好的一档。
4. **这是本轮第一个"两个分段都赢基准"的结果**，但幅度不大（超额约 2pp/年、Sharpe +0.2）。

---

## 五、必须说清楚的局限

1. **幸存者偏差最严重**：成分用的是**当前** HS300 名单，不是历史成分。
   基准等权本身就被抬高（15.6% CAGR），绝对收益不可实盘复现。
   因子组合与基准共享这一偏差，所以"相对"结论比"绝对"结论可信。
2. 财务数据来自 sina，无公告日，统一滞后 90 天；行业只有当前快照。
3. 未做风格暴露分解（barra 类），不清楚超额到底来自低波、动量还是行业偏离。
4. 只有 300 只票、10 年，topN=50 的截面很小。

## 六、下一步（真正能验证的做法）

1. **解决幸存者偏差**：用全 A（含已退市）构造点时成分，或至少用
   "每年按流通市值前 300 名"的规则池，而不是今天的成分。
2. 做**风格中性**：对 size/industry 做中性化后再排序，看超额是否还在。
3. 用**多期 IC / 分组收益**检验因子本身，而不只看组合净值。
4. 若要实盘：先 paper trade 一个季度，确认成交与滑点在 0.1%/边以内。

复现：

```bash
docker run --rm --entrypoint python3 -v $PWD/user_data:/app/user_data \
  -v $PWD/scripts:/app/scripts:ro bullseye:latest \
  scripts/research/multifactor.py --data user_data/data_fund \
  --start 2016-01-01 --end 2026-10-10
```

## 七、点时成分（进行中，2026-10-29 夜）

目标：去掉"当前 HS300 名单"的幸存者偏差，改成**每个月底按流通市值前 300 名**的动态池。

### 已经做好的

1. `scripts/research/fetch_all_a.py`：全 A 日线（5224 只，9 字段），**可断点续传**
2. `scripts/research/build_pit_universe.py`：逐月按
   `close × volume × 100 / turn`（20 日中位）排前 300，输出 `pit_top300.parquet`
3. `multifactor.py` 增加 `--universe pit_top300.parquet`：
   每次调仓只在当期成分内选股，基准也改为"当期成分等权"

### 卡在哪里

baostock 单线程实测约 **13 只/分钟**，5224 只需 ~6 小时；开 8 个并发分片会被限流，
大部分请求返回空（每片只写进 50~65 只就"完成"）。所以只能让它慢慢跑，
已下载的部分会缓存，重跑自动跳过。

### 恢复方式

```bash
# 查看进度
ls user_data/data_all/*-1d.parquet | wc -l        # 目标 ~5000

# 续传（重复执行即可，已下载的会跳过）
docker run -d --name fetch_all_a --entrypoint python3   -v $PWD/user_data:/app/user_data -v $PWD/scripts:/app/scripts:ro   bullseye:latest scripts/research/fetch_all_a.py --out user_data/data_all

# 数据齐了之后
docker run --rm --entrypoint python3 -v $PWD/user_data:/app/user_data   -v $PWD/scripts:/app/scripts:ro bullseye:latest   scripts/research/build_pit_universe.py --data user_data/data_all --top 300

# 再给池内出现过的票补财务（threaded）
docker run --rm --entrypoint python3 -v $PWD/user_data:/app/user_data   -v $PWD/scripts:/app/scripts:ro bullseye:latest   scripts/research/fetch_fundamentals_fast.py --out user_data/data_all_fund

# 跑点时多因子
docker run --rm --entrypoint python3 -v $PWD/user_data:/app/user_data   -v $PWD/scripts:/app/scripts:ro bullseye:latest   scripts/research/multifactor.py --data user_data/data_all_fund   --universe user_data/data_all/pit_top300.parquet
```

### 预期会变差，这是好事

当前 300 只成分等权的 15.6% CAGR 是幸存者偏差抬出来的。换成点时池后，
基准和多因子组合的绝对收益**大概率都会下降**；真正要看的是
"动量+低波 vs 当期池等权"的超额还在不在。如果超额消失，说明第六节那个
Sharpe 1.07 也只是幸存者偏差的另一种表现形式。
