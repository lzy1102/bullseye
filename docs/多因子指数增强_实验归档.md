# HS300 多因子实验归档（2026-10-29）

> 动机：单票技术策略在留出池全灭、ETF 轮动扣掉未来函数后只剩"分散+趋势过滤"。
> 多因子是业界主流路线，先做一次最小可用验证。
> 数据：baostock 日线（peTTM/pbMRQ/turn）+ sina 财务指标（2014 起）+ 证监会行业。
> 口径：HS300 当前成分 300 只，月频调仓，费 0.1%/边，权重 shift(1)（收盘决策、下一根计收益）。

---

## 一、因子与构造

| 因子 | 定义 | 方向 |
|---|---|---|
| value | 1 / pbMRQ | 高 |
| quality | 净资产收益率 ROE（最新已披露） | 高 |
| growth | 净利润同比增长 | 高 |
| mom | `close[t-21] / close[t-252] - 1`（12-1 动量） | 高 |
| lowvol | 60 日收益标准差 | 低 |

- 财务数据**滞后期固定 90 天**（数据源无公告日，宁保守）
- 每月末横截面 winsorize(1%/99%) + z-score，等权合成
- 取分数前 N 等权持有，下月首个交易日调仓
- 可选行业上限（证监会一级行业，每行业 ≤6 只）

---

## 二、过程中修掉的两个 bug（都改变了结论）

1. **权重矩阵初始化为 0.0**：`ffill` 只能填 NaN，填不了 0，导致 95% 的时间空仓，
   组合收益 -6% 而基准 +218%。改为初始化为 NaN。
2. **分段回测没有截断收益**：`ret` 用全样本，权重只覆盖窗口，
   导致 2016-2020 段出现 NaN/错乱。改为 `ret = ret.loc[dates]`。

修正后才得到下面的结果。这两类错误（同 bar 收益、窗口未截断）在自研回测里极常见。

## 四、结论

1. **唯一在两个分段都跑赢等权基准的是 `动量 + 低波`（top50）**：
   Sharpe 1.30 vs 0.98（2016-20）、0.89 vs 0.73（2021-26），全窗口 1.07 vs 0.86，
   收益 17.75% vs 15.60%，回撤基本持平。换手约 6.7 次/年，成本可控。
2. **价值/质量在 A 股这十年是拖累**：value=1/PB 会自动重仓银行地产，
   top50 value+quality 只有 10.6% CAGR，Sharpe 0.71，低于等权。
   五因子等权（13.3%）被它拉低，不如只用动量+低波。
3. **topN 越小收益越高、回撤越大**：top20 CAGR 20.6% 但回撤 −37%；
   top50 是风险收益比最好的一档。
4. **这是本轮第一个"两个分段都赢基准"的结果**，但幅度不大（超额约 2pp/年、Sharpe +0.2）。

---

## 五、必须说清楚的局限

1. **幸存者偏差最严重**：成分用的是**当前** HS300 名单，不是历史成分。
   基准等权本身就被抬高（15.6% CAGR），绝对收益不可实盘复现。
   因子组合与基准共享这一偏差，所以"相对"结论比"绝对"结论可信。
2. 财务数据来自 sina，无公告日，统一滞后 90 天；行业只有当前快照。
3. 未做风格暴露分解（barra 类），不清楚超额到底来自低波、动量还是行业偏离。
4. 只有 300 只票、10 年，topN=50 的截面很小。

## 八、800 只池（沪深300 + 中证500）实测：结论被推翻（2026-11-16）

数据已齐（800 只 K 线 + 800 只财务，2014-2026）。基准改为 **800 只等权**。

### 全窗口 2016-01 ~ 2026-10

| 组合 | 总收益 | CAGR | 最大回撤 | Sharpe | 年换手 |
|---|---|---|---|---|---|
| 800 只等权（基准） | +299.5% | 13.73% | −29.51% | 0.74 | — |
| top50 mom+lowvol | +547.0% | 18.94% | −35.46% | 0.93 | 8.8x |
| top30 mom+lowvol | +672.0% | 20.91% | −39.53% | 0.89 | 9.5x |
| top20 mom+lowvol | +468.5% | 17.52% | −44.52% | 0.73 | 10.1x |
| top50 五因子 | +267.8% | 12.87% | −25.09% | 0.84 | 5.2x |
| top50 value+quality | +163.1% | 9.40% | −22.36% | 0.63 | 2.9x |

### 分段（决定性）

| 窗口 | 组合 | CAGR | 回撤 | Sharpe |
|---|---|---|---|---|
| 2016-2020 | 等权 | 15.08% | −29.51% | 0.75 |
| | **mom+lowvol top50** | **26.58%** | −35.46% | **1.24** |
| | 五因子 top50 | 11.95% | −25.09% | 0.76 |
| | value+quality | 7.88% | −22.36% | 0.51 |
| 2021-2026 | 等权 | 12.26% | −27.04% | 0.71 |
| | mom+lowvol top50 | 12.07% | −34.71% | **0.67** |
| | **五因子 top50** | 12.67% | **−18.12%** | **0.86** |
| | value+quality | 10.82% | −15.64% | 0.76 |

### 结论修正

1. **加入中证500 后，`mom+lowvol` 在 2021-2026 失效**：
   12.07% / 0.67，**低于**等权的 12.26% / 0.71。第六节里 HS300 单池的
   "两段都赢"（0.89 vs 0.73）是**池子造成的**，不是因子本身稳定。
   全窗口 0.93 vs 0.74 的超额**全部来自 2016-2020**（1.24 vs 0.75）。
2. **最稳的是五因子等权**：两个窗口都跑赢等权（0.76 vs 0.75、0.86 vs 0.71），
   2021-2026 回撤只有 −18.1%（等权 −27.0%）。但全窗 CAGR 12.87% 低于等权 13.73%，
   **它是降波动、不是提收益**。
3. **value+quality 依旧不产生收益**（9.40% / 0.63），但 2021-2026 它的
   Sharpe 0.76 已经高于等权、回撤 −15.6%，说明价值只在**熊市防御**上有用。
4. 700 次调仓的换手成本已含 0.1%/边；mom+lowvol 换手 8.8x/年，成本吃掉约 1.8pp/年。

**一句话**：800 只池上没有任何因子组合能稳定跑赢等权收益；能站住的只有
"五因子降回撤"这一条，且是波动率层面的改善。

### 过程中的数据坑

akshare 的 `adjust="qfq"`（前复权）对高分红股会算出**负价格**
（本例 6 只，最差 −4.72 元），把组合收益打成 −inf。已改为只接受正价格，
并用 baostock `adjustflag=2` 重拉了那 40 只。**任何人用 qfq 数据做长周期回测
都必须先查 `close<=0`。**

## 十、宽度与参数敏感性：第八节的结论需要修正（2026-11-18）

第八节说"加入中证500 后 mom+lowvol 在 2021-2026 失效"，那**只在 top50 上成立**。
把持仓宽度拉开，结论反过来：

### 全窗口 2016-01 ~ 2026-10（800 只池）

| 组合 | 总收益 | CAGR | 最大回撤 | Sharpe | 年换手 |
|---|---|---|---|---|---|
| 800 只等权（基准） | +299.5% | 13.73% | −29.51% | 0.74 | — |
| top50 mom+lowvol | +547.0% | 18.94% | −35.46% | 0.93 | 8.8x |
| **top100 mom+lowvol** | +442.8% | **17.02%** | −31.14% | **0.98** | 7.3x |
| **top150 mom+lowvol** | +400.2% | **16.13%** | **−27.67%** | **0.98** | 6.5x |
| top100 五因子 | +266.3% | 12.82% | −26.71% | 0.85 | 4.5x |
| top150 五因子 | +290.9% | 13.50% | −27.94% | 0.88 | 4.2x |

### 分段

| 窗口 | 基准 | mom+lowvol top50 | top100 | top150 |
|---|---|---|---|---|
| 2016-2020 | 15.08% / 0.75 | 26.58% / 1.24 | 20.21% / **1.09** | 18.89% / **1.06** |

**top50 第二段输，是集中度问题**（20 只中小盘高动量股，回撤 −34.7%）；

### 参数敏感性（top100，两窗口 Sharpe）

| 动量窗口 | 2016-2020 | 2021-2026 |
|---|---|---|
| **12-1（252/21）** | **1.09** | **0.89** |
| 6-1（126/21） | 1.13 | 0.64 |
| 3-1（63/21） | 0.94 | 0.37 |
| 12-1 + 120 日波动 | 1.06 | 0.67 |
| 12-1 + 20 日波动 | 1.22 | 0.77 |

短动量窗口在 2021 后迅速衰减（3-1 只剩 0.37），**只有 12-1 与 60 日波动率在两个窗口都成立**，
而这恰好也是文献/业界最常用的默认参数，不是事后挑出来的。

### 结论

**mom+lowvol（12-1 动量 + 60 日低波，持仓 100~150 只）是本次研究里唯一
在两个分段、多个宽度上都稳定跑赢等权的组合**：年化 +2.4~3.3pp，Sharpe 0.98 vs 0.74。

仍要打三个折扣：

1. **多重检验**：本项目累计试过几十组因子/宽度/参数，挑出一个在样本内稳定的组合
   本身不能证明有效；真正的检验是第十一节的点时池（样本外）。
2. **幸存者偏差**：池子是今天的 800 只成分，绝对收益偏乐观。
3. **换手成本**：已含 0.1%/边，年换手 6.5~7.3 次，实盘冲击成本可能再吃掉 1pp。

## 十一、严格点时池：幸存者偏差被量化（2026-11-19）

全 A 5130 只日线齐了（2014-2026）。每月底按 20 日流通市值中位数排前 300，
**用当月的成分**做截面选股，基准换成当期成分等权。

池子规模：154 个月，1019 个不同名字，月均换手 5.4%。
2016-06 的前十名是 601857/601398/601288/601988/601628/600519…（市值中位 207 亿），
说明排序是对的。

### 结果

| 窗口 | 组合 | 总收益 | CAGR | 回撤 | Sharpe |
|---|---|---|---|---|---|
| 2016-2020 | PIT 300 等权（基准） | +36.3% | 6.40% | −34.92% | 0.41 |
| | mom+lowvol top50 | +124.1% | **17.55%** | −32.11% | **0.96** |
| | mom+lowvol top100 | +81.8% | 12.73% | −28.23% | 0.78 |
| | 五因子 top50 | +71.3% | 11.38% | −26.94% | 0.76 |
| 2021-2026 | PIT 300 等权（基准） | +3.9% | 0.67% | −35.82% | 0.13 |
| | mom+lowvol top50 | +20.4% | **3.27%** | −33.96% | **0.27** |
| | mom+lowvol top100 | +21.1% | 3.38% | −29.26% | 0.30 |
| | 五因子 top50 | +26.0% | 4.10% | −25.41% | 0.34 |
| 2016-2026 | PIT 300 等权（基准） | +74.3% | 5.30% | −34.92% | 0.37 |
| | mom+lowvol top50 | +180.4% | **10.05%** | −36.79% | **0.60** |
| | mom+lowvol top100 | +123.7% | 7.77% | −29.26% | 0.54 |
| | 五因子 top50 | +128.1% | 7.96% | −26.94% | 0.57 |

### 两个结论

1. **幸存者偏差的量级：8.4pp/年。** 同样是"大市值等权"这个口径，
   用今天的 800 只成分回测是 13.73%/年，用时点池只有 5.30%/年。
   **第八~十节里所有绝对收益都不成立**，只能读相对差值。
2. **因子的相对超额活下来了，而且在低收益环境里更明显**：
   mom+lowvol top50 两段都赢基准（17.55% vs 6.40%、3.27% vs 0.67%），
   Sharpe 0.96 vs 0.41、0.27 vs 0.13。
   但 2021-2026 的绝对水平（+3.3%/年）**没有实盘价值**，
   而且回撤 −34%，和基准一样难受。

**净结论**：mom+lowvol 是"比等权少亏"的改进，不是"能赚钱"的策略。
在 2021-2026 这种大市值整体不涨的环境里，任何多头组合都很难看。

### 两个真 bug（都出在"点时掩码"上，且都是静默错误）

1. **`ffill` 对 bool 矩阵是空操作**：`DataFrame(False)` 里没有 NaN 可填，
   `ffill()` 什么也不做，于是"当期成分"只在月末那一天生效、其余日子全空仓。
   表现为基准年化 2.7%、因子组合全 0。必须用 `NaN` 初始化再 `ffill().fillna(False)`。
   （同类错误第二次出现：之前是权重矩阵初始化成 `0.0` 导致 `ffill` 失效。）
2. **月末快照 vs 月初调仓**：`universe.get(调仓日)` 永远取不到值，
   必须取"最近一个不晚于调仓日的快照"（`searchsorted`）。否则组合永远空仓、输出 0.0%。
